# Familit · 패밀릿

**가족을 챙기는 마음을 실제 행동으로 연결하는 가족 케어 서비스입니다.**

부모님과 떨어져 사는 자녀가 생일·건강검진·생활 업무를 놓치지 않도록, 흩어진 할 일을 케어 액션 카드와 체크리스트로 정리하는 경험을 설계했습니다.

## 문제와 접근

가족을 챙기는 일은 일정을 기억하는 것에서 끝나지 않습니다. 무엇을 준비하고 누가 행동할지 정해야 합니다. Familit은 날짜보다 **가족을 위해 해야 할 행동**을 중심에 둡니다.

| 사용자 경험 | 설계 의도 |
|---|---|
| 케어보드 | 가족을 위해 챙길 행동을 카드로 한눈에 파악 |
| 액션 카드·체크리스트 | 막연한 관심을 구체적인 준비와 실행으로 전환 |
| 가족 응답 시뮬레이션 | 디지털 사용에 익숙하지 않은 가족의 참여 방식 탐색 |
| 요금제·테스트 결제 | 서비스 가치와 유료 경험을 연결하는 흐름 구성 |
| 신뢰 안내 | 가족·생활 정보를 다루는 서비스의 설명 책임 반영 |

## 주요 화면

- 서비스 랜딩과 가족 케어 사례
- 클릭형 케어보드·가족 액션 카드 데모
- 데이터·접근 제어 안내
- Plus 요금제, 결제위젯, 승인·실패 결과 화면

## 기술과 구조

React 19 · TypeScript · TanStack Start/Router/Query · Vite · Tailwind CSS · Supabase · Toss Payments SDK

파일 기반 라우팅으로 화면을 구성하고 결제 승인 처리는 서버 함수로 분리했습니다. Supabase 연동 기반과 인증 전달 미들웨어, 서버 렌더링 오류 처리를 함께 구성했습니다. 초기 Next.js 접근은 별도 소스 보관본에 남겼습니다.

## 프로젝트 범위

클릭형 데모와 테스트 결제를 다룬 프로토타입입니다. 데모 상호작용은 실사용 가족 데이터 저장이나 실제 AI 제공을 의미하지 않으며, 결제 이용권 발급·상용 운영을 보장하지 않습니다. 건강 관련 내용은 생활 관리 참고 수준으로 다룹니다.
