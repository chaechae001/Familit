# 2026-10-27 정리 및 결정

- 원격 TanStack 앱을 현재 기준으로 유지하고 로컬 테스트 결제를 추가했습니다.
- 초기 Next.js 버전은 덮어쓰거나 삭제하지 않고 저장소의 `archives/`로 복사했습니다.
- npm 설치 재현을 위해 로컬 잠금 파일의 버전을 기준으로 직접 의존성을 고정했습니다. 기존 Bun 잠금 파일과의 혼동은 검증 기록에서 안내합니다.
- 오래된 인수인계 원문의 내부 프로젝트 식별자·실제 환경변수는 새 문서에 옮기지 않았습니다.
- 이번 작업은 기능 보존과 작업 재개 준비입니다. 실제 결제 완료·AI 제공·실사용 가족 공유를 성과로 추가하지 않습니다.

- 자동 생성 Supabase 파일은 수동 포맷하지 않고 Prettier 대상에서 제외했습니다. 일반 화면과 결제 함수의 형식을 정비해 전체 lint 오류를 해소했습니다.
- Windows의 Cloudflare preview 실행 문제를 위해 Node 로컬 미리보기 스크립트를 추가했습니다.
