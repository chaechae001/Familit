# Familit 진행 현황

기준일: 2026-10-27. 코드 확인 기준이며 외부 서비스의 운영 상태를 확정하지 않습니다.

## 완료된 소스

- TanStack 기반 랜딩, 클릭형 가족 케어 데모, 신뢰 안내 화면.
- 로컬 2026-07-10 버전의 Plus 요금제·결제위젯·성공/실패 화면과 서버 승인 함수 통합.
- 원격의 Supabase 인증 전달 미들웨어와 SSR 오류 처리 유지.
- 초기 Next.js 두 구현을 `archives/next-phase0`, `archives/next-phase1`에 보존.
- 한국어 문서의 언어 속성 정비, 환경변수 예시와 재현 설치 안내 추가.

## 구현과 운영 검증을 구분할 항목

- 케어보드의 클릭형 데모는 실제 가족 데이터 CRUD 완료의 증거가 아닙니다.
- 초기 Next.js 로그인 폼은 존재하지만 온보딩은 placeholder, 홈은 mock 데이터입니다.
- 테스트 결제 승인 함수는 플랜 금액·주문번호·응답을 검사하지만 서버 주문 원장·권한·중복 처리·이용권 발급은 미구현입니다.
- AI 체크리스트와 가족 간 응답은 시연이며 실제 AI·공유 서비스로 검증하지 않았습니다.
- DB 마이그레이션은 보존만 했으며 원격 Supabase에 적용하지 않았습니다.

## 다음 우선순위

1. 실제 Auth → 가족 그룹 → 케어 카드 저장까지 한 사용자 흐름 구현.
2. 서비스 개인정보 동의와 접근 제어 검증.
3. 결제 원장과 이용권을 구현한 뒤 테스트 승인·취소 흐름 검증.
4. 실제 AI는 사용자 입력과 저장 흐름이 안정된 뒤 서버에서 연동.
